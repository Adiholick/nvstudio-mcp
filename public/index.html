nvstudio-mcp v2.3.0

Jembatan pintar berbasis Model Context Protocol (MCP) yang menghubungkan AI Agent (Antigravity IDE, Cursor, Claude Desktop, Windsurf) secara langsung ke dalam Roblox Studio.

GitHub Repository NPM Package

🚀 Fitur Baru v2.3.0

  • ⚡ Batch Instance Builder: Membangun pohon hierarki GUI puluhan tingkat dalam 1 kali roundtrip via batch_create_instances dan update massal via batch_set_properties.
  • 🛡️ Asset Security Scanner: Memindai dan memusnahkan 10 jenis ancaman backdoor/malware pada aset sebelum dimasukkan ke game via preview_asset dan scan_security.
  • 📚 Live Creator Docs Lookup: Mengambil dokumentasi engine resmi dari Roblox Creator Docs secara offline/online dengan disk cache berkecepatan ~2 ms via get_roblox_docs.
  • 🎨 NV-Series GUI Standard Taste: Standardisasi tata letak Frame, LayoutOrder teratur, Spacer margin ScrollingFrame, dan deteksi perangkat responsif pintar (PC, Phone, Tablet, Console).

🛠️ Daftar Semantic MCP Tools Lengkap

  • batch_create_instances — Pembuatan objek/hierarki massal pohon bersarang.
  • batch_set_properties — Pembaruan properti multi-instance secara atomik.
  • get_roblox_docs — Lookup dokumentasi resmi engine Roblox (Class, Datatype, Service, Enum).
  • preview_asset / scan_security — Audit keamanan backdoor & sanitasi script model.
  • patch_script_source — Mengedit bagian baris kode tertentu secara parsial.
  • execute_luau — Eksekusi sembarang kode Luau dinamis di Studio.
  • get_full_tree / get_children — Eksplorasi hierarki DataModel.
  • insert_asset / generate_terrain — Memasukkan model atau membuat terrain voxel.
