nvstudio-mcp

Jembatan pintar berbasis Model Context Protocol (MCP) yang menghubungkan AI Agent (Antigravity IDE, Cursor, Claude) secara langsung ke dalam Roblox Studio. AI Anda dapat membaca, menulis, dan mengeksekusi script layaknya Co-Pilot sejati.

GitHub NPM Package

Cara Kerja

  • Plugin Roblox Studio melakukan polling ke server MCP Bridge ini setiap detik.
  • AI Agent mengirimkan perintah melalui tool call_mcp_tool.
  • Bridge meneruskan perintah ke Studio dan mengembalikan hasilnya ke AI.
  • Dashboard ini menampilkan semua aktivitas secara real-time via WebSocket.

Commands yang Tersedia

  • get_children — Daftar children dari instance
  • get_script_source — Baca source code script
  • update_script_source — Tulis/perbarui source code
  • rollback_script — Rollback ke versi sebelumnya
  • get_logs — Ambil log output Studio
