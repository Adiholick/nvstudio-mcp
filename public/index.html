nvstudio-mcp v2.0.0

Jembatan pintar berbasis Model Context Protocol (MCP) yang menghubungkan AI Agent (Antigravity IDE, Cursor, Claude) secara langsung ke dalam Roblox Studio.

GitHub NPM Package

⚡ Arsitektur v2.0 Baru

  • Zero-Delay Long-Polling: Plugin Studio kini menunggu task secara realtime hingga 20 detik tanpa putus. Memangkas latensi drastis menjadi < 50ms (dibandingkan polling 1-detik di v1).
  • Luau Pre-Commit Validator: Mencegah engine Roblox crash dengan memvalidasi sintaks Luau sebelum kode dikirim ke Studio.
  • Partial Script Patching: AI kini menggunakan metode patch_script_source (pengeditan parsial per baris) yang jauh lebih cepat dan menghemat ribuan token.

🛠️ Commands MCP Unggulan

  • patch_script_source — Mengedit bagian spesifik dari script (super cepat).
  • execute_luau — Menjalankan script Luau secara realtime di Studio.
  • insert_asset — Memasukkan model 3D/asset dari library Roblox.
  • generate_terrain — Men-generate atau memanipulasi terrain voxel.
  • get_children / get_script_source — Inspeksi hirarki dan source code.
