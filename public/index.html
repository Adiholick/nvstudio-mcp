nvstudio-mcp v2.4.3

                        
Jembatan pintar berbasis Model Context Protocol (MCP) yang menghubungkan AI Agent (Antigravity IDE, Cursor, Claude Desktop, Windsurf) secara langsung ke dalam Roblox Studio.

                        

                            
                                
                                GitHub Repository
                            
                            
                                
                                NPM Package
                            
                        

                    


                    

                        
🚀 Fitur Baru v2.4.3

                        
    
                            
  • ✨ VFX Instance Structure Standard: Penegakan aturan mutlak pembuatan VFX wajib berupa Roblox Instance konkret di hierarchy DataModel (misal ReplicatedStorage.VFX) menggunakan semantic tools MCP, bukan script Luau hardcoded Instance.new. Script Luau hanya berfungsi sebagai runtime controller/trigger.
    • 
                            
  • 🦴 Human-Like Motion Kinematics & Anti-Dislocation: Penegakan batas anatomis sendi anti-patah tulang (siku/lutut 1-DOF hinge dengan larangan mutlak sudut negatif < 0° serta larangan roll/yaw).
    • 
                            
  • 🎯 Joint Isolation & Foot-Planting: Hanya menggerakkan primary movers sendi yang relevan secara biomekanik, mencegah flailing spastik acak, dan menjaga tumpuan kaki stabil di tanah.
    • 
                            
  • 🦴 NV-Rig Engine: Rigging headless presisi $O(1)$ untuk R6, R15, dan Custom Rig. Menyediakan inspeksi sendi (inspect_rig), pemindahan poros C0/C1 simultan anti-dislokasi (edit_rig_joint), auto-rigging instan (auto_rig), dan assembly welding senjata/prop (weld_assembly).
    • 
                            
  • 🎬 NV-Animation Engine: Pembuatan animasi karakter halus alami (Walk, Slash, Punch, Idle, IK) langsung menjadi KeyframeSequence resmi dengan interpolasi Bezier (Cubic/Quad).
    • 
                            
  • ✨ NV-VFX Subsystem & Database: Serialisasi efek visual (ParticleEmitter, Beam, Trail, PointLight) lintas-proyek dengan tool scan_vfx dan rekonstruksi instan via apply_vfx.
    •
